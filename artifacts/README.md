# `artifacts/` directory

Sample data, generated outputs, and source documents used by the notebooks live here.

## Input files sourced from Anthropic's course materials

The following files originated from Anthropic's *Building with the Claude API* course and are used here for the corresponding course exercises:

- `earth.pdf` — input to Notebook 06's PDF input demo
- `images/prop1.png` through `images/prop7.png` — input to Notebook 06's image input / fire-risk-assessment demo
- `streaming.csv` — input to Notebook 06's code execution + Files API demo

If Anthropic prefers these not be redistributed, they can be replaced with novel equivalents (open-data property imagery, public-domain PDFs, synthetic CSVs) without changing the notebooks' logic.

## Generated by running the notebooks

Everything else in this directory is produced by running the notebooks in this repo:

- `dataset.json`, `dataset_with_format.json`, `prompting_exercise_dataset.json` — eval datasets generated by Notebook 02 / 03
- `output.html`, `output.json` — eval reports generated by Notebook 02
- `report.md` — RAG source document used by Notebook 05
- `churn_driver_analysis.png` — visualization output by Notebook 06's code execution cell
- `main.py`, `test.py` — small helper scripts

Generated content is licensed under the [MIT license](../LICENSE) at the repo root.
